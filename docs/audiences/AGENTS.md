# Audiências e Targeting

Documentação completa sobre públicos e segmentação na API de Marketing do Facebook.

## Visão Geral

A API de Audiências permite criar e gerenciar públicos personalizados, semelhantes e direcionamento detalhado para campanhas de anúncios.

## Tipos de Público

1. **Custom Audiences** - Públicos personalizados baseados em dados próprios
2. **Lookalike Audiences** - Públicos semelhantes aos seus clientes
3. **Saved Audiences** - Combinação de targeting demográfico e interesses
