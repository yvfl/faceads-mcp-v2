# Get Started



This guide explains how to successfully set up your catalog for automotive ads.

## Before you start

To create automotive ads, you need a [Facebook Page](https://www.facebook.com/pages/create/) and an [ad account](https://www.facebook.com/ads/manager/accounts).

## Step 1: Create your automotive catalog

To create an [automotive catalog](auto-ads/guides/catalog.md), connect a data feed or upload data to Meta servers. The data should contain all the required fields for the vehicles that you want to advertise. The [Reference](auto-ads/reference.md) lists the required fields.

## Step 2: Set up automotive events on your website

Automotive ads use [standard and required events](auto-ads/guides/events.md), and every event has a set of parameters. You can use the Meta Pixel on your website and mobile app events in your Android app and iOS app.

## Step 3: Build your automotive audience

To successfully [build and manage your audience](auto-ads/guides/audience-mgmt.md), you can:

* [Associate your Pixel with your catalog](auto-ads/guides/audience-mgmt.md#associate-pixel)
* [Retarget an audience](auto-ads/guides/audience-mgmt.md#retarget)

## Step 4: Create and start your automotive ads

This step assumes you have a catalog and product set ready, and have set up the required vehicle events on your website or in your mobile app. If not, see [catalog setup](auto-ads/guides/catalog.md) and [event setup](auto-ads/guides/events.md).
