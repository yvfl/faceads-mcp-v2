## Formatos de Anúncio

| Formato | Descrição |
|---------|-----------|
| **Single Image** | Uma única imagem |
| **Single Video** | Um único vídeo |
| **Carousel** | Múltiplas imagens/vídeos roláveis |

| **Instant Experience** | Experiência imersiva full-screen |
| **Lead Form** | Formulário de captura de leads |
