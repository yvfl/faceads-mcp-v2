# 2025 Out-of-cycle changes



This page lists the 2025 out-of-cycle changes to the Marketing API.

### December 8, 2025

When creating ad sets, the `regional_regulated_categories` field now accepts `BRAZIL_REGULATION` as a value. The corresponding `regional_regulation_identities` fields are `universal_beneficiary` and `universal_payer`.

If you are seeing "No beneficiary/payer provided" errors, use the `BRAZIL_REGULATION` value to declare that an ad set targets a Brazilian audience. You may also receive an email or notification if the `BRAZIL_REGULATION` value is required.

**Example:**
```
{
regional_regulated_categories:["BRAZIL_REGULATION"],
regional_regulation_identities:{
"universal_beneficiary": <UNIVERSAL_BENEFICIARY_ID>,
"universal_payer": <UNIVERSAL_PAYER_ID>
}
}
```

### October 29, 2025

### Insights

*Applies to all versions on October 29, 2025.*

Introducing the `instagram_profile_visits` insights metric that measures the number of times users visit an advertiser's Instagram profile as a result of interacting with an ad. Instagram profile visits include clicks on the ad's CTA button, profile picture, or username that lead directly to the Instagram profile.

This change affects the following endpoints:

* [`GET /{campaign-id}/insights`](reference/ad-campaign-group/insights.md)
* [`GET /{ad-set-id}/insights`](reference/ad-campaign/insights.md)
* [`GET /{ad-id}/insights`](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/adgroup/insights)

### October 28, 2025

### Threads Ads

- Advantage+ catalog ads are now available for Threads ads. Only images and image carousels are currently supported. Slideshow, video and entry cards are not supported at this time. See [Threads Advantage+ Catalog Ads](ad-creative/threads-ads/creation/advantage-catalog-ads.md) for more information.

### October 13, 2025

### Ads Insights API upcoming changes
*Applies to all versions on January 12, 2026.*

* **Attribution Windows**: Data for 7-day view-through (`action_attribution_windows=7d_view`) and 28-day view-through (`action_attribution_windows=28d_view`) attribution windows will no longer be available and will return no data
* **Historical Data**: Certain fields and breakdowns will have limited historical data retention and will return no data when queried with `start_date`s beyond their retention limits:
    * *Limited to 13 months:* All breakdowns for unique-count fields (like `unique_actions` and `cost_per_unique_action_type`); and hourly breakdowns for all fields (i.e., `breakdowns=hourly_stats_aggregated_by_advertiser_time_zone`)
    * *Limited to 6 months*: Frequency breakdowns (i.e., `breakdowns=frequency_value`)
* **MMM Breakdowns**: MMM breakdowns (i.e., `breakdowns=mmm`) will be limited to asynchronous jobs.

The following endpoints are affected:

* [`GET /{ad-account-id}`](reference/ad-account/insights.md)
* [`GET /{campaign-id}`](reference/ad-campaign-group/insights.md)
* [`GET /{ad-set-id}`](reference/ad-campaign/insights.md)
* [`GET /{ad-id}`](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/adgroup/insights)
* [`POST /{ad-account-id}`](reference/ad-account/insights.md)
* [`POST /{campaign-id}`](reference/ad-campaign-group/insights.md)
* [`POST /{ad-set-id}`](reference/ad-campaign/insights.md)
* [`POST /{ad-id}`](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/adgroup/insights)

### October 9, 2025

### Placements

#### Messenger inbox
*Applies to v23.0+. Will apply to all versions on November 11, 2025.*

The Messenger Inbox placement (`messenger_home`) will no longer be available for targeting for ads creation.

The following endpoints will be affected:

* [`GET /{ad-account-id}/adsets`](reference/ad-account/adsets.md)
* [`POST /{ad-account-id}/adsets`](reference/ad-account/adsets.md)
* [`GET /{ad-set-id}?fields=targeting`](reference/ad-campaign.md)

### October 6, 2025

### Threads Ads

- Image carousel can now be used for Threads ads. Placement customization and allow product video are not supported. See [Threads Carousel Ads](ad-creative/threads-ads/creation/carousel-ads.md) for more information.

### September 18, 2025

### Special Ad Categories

#### Social issues, elections, and politics
*Applies to all versions.*

Beginning October 6, 2025, in response to the European Union's Transparency and Targeting of Political Ads (TTPA) regulation, social issues, electoral, and political ads will no longer be allowed in the European Union. [Learn more.](https://about.fb.com/news/2025/07/ending-political-electoral-and-social-issue-advertising-in-the-eu/)

The following endpoints are affected:

* [`POST /{ad_account_id}/campaigns`](reference/ad-account/campaigns.md)
* [`POST /{ad_account_id}/ads`](reference/ad-account/ads.md)
* [`POST /{ad_account_id}/adsets`](reference/ad-campaign.md)
* [`POST /{ad_account_id}/adcreatives`](reference/ad-account/adcreatives.md)

### September 2, 2025

### Live special price in Catalog API
*Applies to: v23.0+*

Sellers can sync `live_special_price` to `product_item` in catalogs indicating a live-only special promotion price for a product. The price has 2 digits added for cents (ex: use '100' for 1 or '599' for 5.99).

The following endpoints are affected:
* [`POST /{product_catalog_id}/products`](reference/product-catalog/products.md)
* [`POST /{product_item_id}`](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/product-item#Updating)
* [`GET /{product_item_id}`](https://developers.facebook.com/documentation/ads-commerce/marketing-api/reference/product-item#Updating)
* [`POST /{product_catalog_id}/items_batch`](reference/product-catalog/items_batch.md)


### August 19, 2025

### Audiences

#### Basic targeting
*Will apply to all versions August 19, 2025.*

`COMSCORE_MARKET` codes are a new geomarket source in location targeting for ad set creation. You can now use Comscore Markets as a source along with existing DMA (Designated Market Areas) regions.

The following endpoints are affected:

* [`POST /{ad-account-id}/adsets`](reference/ad-account/adsets.md)

#### Targeting search
*Will apply to all versions August 19, 2025.*

`COMSCORE_MARKET` codes will be returned along with DMA regions when using targeting search.

The following endpoints are affected:

* `GET /search`

### August 18, 2025

### Ad Set Budget Sharing
*Applies to: v21.0+*

The `is_adset_budget_sharing` field will be added to campaign creation API. Advertisers can enable [ad set budget sharing](https://www.facebook.com/business/help/1388266028979935?ref=search_new_0) by setting this field to **True**. With ad set budget sharing, advertisers can now share up to 20% of their budget with other ad sets in the same campaign.

The following endpoints are affected:
* [`POST /act_{ad-account-id}/campaigns`](reference/ad-account/campaigns.md)


### August 15, 2025

### Threads Ads

- Threads ads now supports video ads. See [Threads ads creatives: Media requirements](ad-creative/threads-ads/creation.md#media-requirements) for more information.

- Threads has been added as a `publisher_platform` in the `customization_spec` for Placement Asset Customization. See [Supported Fields in `customization_spec`](dynamic-creative/placement-asset-customization.md#supported-fields) for more information.

### May 1, 2025

### Add new field with value semantic type to promoted object
*Applies to: v22.0+*

Adding a new field to the ad set promoted object to capture the intended value semantics to use when running a campaign with an objective to maximise total value.

The following endpoints are affected:
* [`GET /{ad-set-id}?fields=promoted_object{value_semantic_type}`](reference/ad-promoted-object.md)
* [`POST /{ad-set-id}`](reference/ad-campaign.md)


### March 31, 2025

### Audiences
*Applies to all versions March 31, 2025.*

* The `notification` placement has been added to `facebook_positions` for [placement targeting](audiences/reference/placement-targeting.md) and [placement asset customization](dynamic-creative/placement-asset-customization.md).

### March 10, 2025

### Ads Insights API upcoming change
*Applies to all versions on June 10, 2025.*

On June 10, 2025, Ads Insights API behavior will change in two ways:

* To reduce discrepancies with Meta Ads Manager, `use_unified_attribution_setting` and `action_report_time` parameters will be disregarded, and API responses will mimic Meta Ads Manager settings. To learn more, see the [discrepancy with Ads Manager guidance](insights.md#discrepancy-with-ads-manager).
* To improve overall API performance, `reach` will no longer be returned for queries that apply breakdowns and use `start_date`s more than 13 months old; developers may leverage asynchronous jobs to request such data. To learn more, see the [Insights best practices](insights/best-practices.md).

### January 14, 2025

### Special Ad Categories

*Applies to all versions.*

As introduced in October 2024, there is a new Special Ad Category input for the `special_ad_categories` field. This input is `FINANCIAL_PRODUCTS_SERVICES` representing the [Financial products and services](https://www.facebook.com/business/help/510724041294968) category, and will replace the `CREDIT` input as of January 14, 2025. This change is part of the expansion of special ad categories to include financial products and services in early 2025. Learn more about the [Financial products and services category](https://www.facebook.com/business/help/510724041294968) or see the [Special ad category documentation](audiences/special-ad-category.md).

**`CREDIT` will no longer be a valid special ad category selection after it is deprecated on January 14, 2025. Developers should migrate to using the `FINANCIAL_PRODUCTS_SERVICES` input prior to the deprecation to avoid campaign setup disruption.** If an ad is created with the CREDIT category after January 14, the API call will fail, and will be blocked with an error message. Prioritize this update well in advance of the deprecation date to minimize disruption for your customers.

Businesses that have selected the `FINANCIAL_PRODUCTS_SERVICES` input must comply with [audience restrictions](audiences/special-ad-category.md#hec-restrictions), similar to housing and employment.

The following endpoints are affected:

* [`POST /{campaign-id}`](reference/ad-campaign-group.md)
