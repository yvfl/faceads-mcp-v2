# 2023 Out-Of-Cycle Changes


This page lists the 2023 out-of-cycle changes to the Marketing API.

## June 6, 2023

### Instagram Ads API

#### Instagram Shop tab placement

The Instagram Shop tab ad placement (`"instagram_positions": ["shop"]`) is no longer available for new ad campaigns.

This change affects the following endpoints when creating ads:

* [POST /{ad-account-id}/adsets](reference/ad-campaign.md)
* [POST /ad_set_id](reference/ad-campaign.md)
* [GET /{ad-id}/previews](generatepreview.md)
* [GET /{ad-account-id}/generatepreviews](generatepreview.md)
