## Fluxo Básico

1. **Autenticação**: Obter token de acesso
2. **Criar Campanha**: Definir objetivo
3. **Criar Ad Set**: Definir público e orçamento
4. **Criar Creative**: Preparar mídia e texto
5. **Criar Ad**: Associar creative ao ad set
6. **Monitorar**: Acompanhar métricas

## Pré-requisitos

- Conta de desenvolvedor Meta
- App registrado
- Conta de anúncios
- Token de acesso com permissões necessárias
