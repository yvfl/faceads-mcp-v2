# Comprehensive reporting


Pull detailed reporting on your campaigns and gain insights into what's working, what changed, and how you compare against industry benchmarks.

| Tool | Description |
|---|---|
| `ads_get_ad_entities` | Retrieve ad campaigns, ad sets, and ads with performance metrics (spend, impressions, CTR, CPC, CPM, conversions), plus filtering, breakdowns, sorting, and date ranges. |
| `ads_get_opportunity_score` | Return the ad account's optimization score (0–100) along with actionable recommendations for improving performance. |
| `ads_insights_advertiser_context` | Summarize business context and marketing funnel to help pick the right optimization goal. |
| `ads_insights_anomaly_signal` | Detect unusual patterns or deviations in ad performance that warrant investigation. |
| `ads_insights_auction_ranking_benchmarks` | Show which ads performed best in the auction and where bid or ad-quality investment would help. |
| `ads_insights_industry_benchmark` | Compare ad set performance against benchmarks from similar advertisers. |
| `ads_insights_performance_trend` | Track how key performance metrics (CPC, CPM, cost per result, ROAS, CTR, conversion rate) change over time. |
