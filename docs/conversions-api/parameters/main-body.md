# Main Body Parameters



| Parameter | Description |
| --- | --- |
| `data`<br><br>array<object> | **Required.**  <br>An array of server event objects. See [Server Event Parameters](conversions-api/parameters/server-event.md) for more information. |
| `test_event_code`<br><br>string | **Optional.**  <br>Code used to verify that your server events are received correctly by Facebook. Use this code to test your server events in the Test Events feature in Events Manager. See [Test Events Tool](conversions-api/using-the-api.md#testEvents) for an example. |
