# Catálogo de Produtos

Documentação sobre catálogos de produtos para anúncios dinâmicos e e-commerce.

## Visão Geral

A API de Catálogo permite gerenciar feeds de produtos para anúncios dinâmicos, Compras no Instagram e Facebook Shops.

## Campos Principais de Produto

- `id` - ID único do produto
- `title` - Nome do produto
- `description` - Descrição
- `availability` - Disponibilidade (in stock, out of stock)
- `condition` - Condição (new, refurbished, used)
- `price` - Preço
- `link` - URL do produto
- `image_link` - URL da imagem
- `brand` - Marca
