# Temporary User Creation



This feature allows customers to create temporary users that have limited access time. Under the **User management** tab, you can now:

1. Add a temporary user, with the ability to add access to multiple accounts.
2. Edit the roles created for each account.  
3. Extend or reduce the access expiry timelines as needed.  

To create a temporary user:

1. Go to the **Users** section and click on **Invite a new user**.
2. Select **Individual user**.

To provide permissions to an account, follow these steps:

1. Choose the account to which you want to grant permissions.
2. Choose the specific permissions you want to grant to the selected account.
3. Ensure that the 'Account Expiry' option is checked. This action will designate the user as a temporary user.
4. Choose the date on which the account will expire and lose the granted permissions.

This process will effectively create a temporary user with specific permissions that will last until the set expiry date.
