# Event Filtering



You can filter which events are received and sent at the data pipeline level by blocking events from being received by the pipeline, or by blocking certain events from being sent to individual data destinations.

## Data Pipeline Filter

To block an event type for the entire data pipeline, go to the **pipeline page** and click on the **pipeline filter component**.

In the modal, you can either select from a predefined standard event or type in a custom event.

## Pipeline Destination Filter

The pipeline destination event filter will appear when you have multiple data destinations for a single data pipeline.

To block event types for a single destination in the data pipeline, but not all data destinations for the data pipeline, go the the **pipeline page** and click on the filter **next to the Data destinations**:

In the modal, you can either select from a predefined standard event or type in a custom event.
