# Insights e Analytics

Documentação sobre a API de Insights para métricas e relatórios de anúncios da Meta.

## Visão Geral

A API de Insights permite obter métricas de performance de campanhas, ad sets, anúncios e conta de anúncios. Suporta agregação por diferentes níveis, períodos de tempo e detalhamentos.

## Tópicos Principais

- **Métricas básicas**: impressions, reach, clicks, spend, cpc, cpm, ctr
- **Conversões**: actions, conversions, purchase_roas
- **Detalhamentos**: age, gender, country, placement, device_platform
- **Períodos**: date_preset (today, last_7d, last_30d, etc.)
