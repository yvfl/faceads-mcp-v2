# Ad Account User



## Reading

Data of App Scoped User.

```html
curl GET \
https://graph.facebook.com/v25.0/act_<AD_ACCOUNT_ID>?fields={fieldname_of_type_AdAccountUser}
```

#### Parameters

This endpoint doesn't have any parameters.

#### Fields

| Field | Description |
| --- | --- |
| `id`<br><br>*numeric string* | ID of the App Scoped User<br> |
| `name`<br><br>*string* | User public full name<br><br><br>**[default]**<br> |
| `tasks`<br><br>*list<string>* | Tasks of App Scoped User<br><br><br>**[default]**<br> |
